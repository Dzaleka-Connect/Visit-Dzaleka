## Extension Name

Visit Dzaleka

## Short Description (132 chars max)

Quick access to Visit Dzaleka — view bookings, explore camp zones, read blog posts, and get real-time alerts from your toolbar.

## Detailed Description

Visit Dzaleka puts your entire Dzaleka Refugee Camp visit experience right in your browser toolbar.

**Dashboard**
See your booking stats at a glance — upcoming, completed, and total visits. A live countdown timer shows exactly how long until your next tour. The role-aware workflow hub adapts for visitors, guides, staff, and security so each user sees the most useful shortcuts first.

**Explore**
Browse all camp zones and points of interest without leaving your browser. Each zone and POI shows its full description so you can plan your visit ahead of time.

**Blog**
Stay informed with the latest posts from the Visit Dzaleka blog. Thumbnails, excerpts, and publish dates are displayed right in the popup. Click any post to read the full article on the website.

**Alerts**
Get real-time notifications about booking confirmations, cancellations, and tour completions. Unread notifications show a badge on the extension icon. Alerts are filtered by role, and a "View" button links you directly to the relevant page.

**Search**
Instantly search across zones, points of interest, and blog posts. Results appear as you type with color-coded icons for each category.

**Dark Mode**
Toggle between light and dark themes. Your preference is saved between sessions.

**Booking Verifier**
Check your booking status by reference number from either the login screen or your signed-in dashboard.

**Keyboard Shortcut**
Open the extension instantly with Cmd+Shift+D (Mac) or Ctrl+Shift+D (Windows/Linux).

## Privacy Practices

### Single Purpose Description

This extension provides quick toolbar access to the Visit Dzaleka platform, allowing users to manage tour bookings, view camp information, read blog posts, and receive booking notifications.

### Permissions Justification

| Permission | Reason |
|------------|--------|
| `storage` | Saves user preferences (dark mode setting) locally on the device |
| `notifications` | Delivers desktop alerts for new booking updates |
| `alarms` | Polls for new notifications every 5 minutes in the background |
| `host_permissions` (`visit.dzaleka.com`) | Fetches user data, bookings, blog posts, zones, and notifications from the Visit Dzaleka API |

### Data Usage Disclosure

- **Personally identifiable information**: Not collected. User data is fetched from the Visit Dzaleka server using existing session cookies and is never stored locally (except dark mode preference).
- **Authentication tokens**: Not stored. The extension uses the browser's existing session cookies for `visit.dzaleka.com`.
- **Health, financial, or payment information**: Not collected.
- **Web history or browsing activity**: Not collected.
- **User activity monitoring**: Not performed.

### Remote Code

This extension does not use any remotely hosted code. All JavaScript runs locally from the extension package.
